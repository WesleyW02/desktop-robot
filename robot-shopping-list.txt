【⚠ 下单必看】
----------------------------------------
 1. 主控必须 N16R8（16MB Flash+8MB PSRAM）
 2. USB-C 数据线必须支持数据传输
 3. 舵机建议 MG90S 金属齿
 4. TT 马达必须带编码器，否则走不直
 5. 电源必须独立（18650+升压5V），电机瞬间
    电流 USB 带不动
 6. 防跌落红外 ×2 朝下装，桌面边缘必刹停
 7. 麦克风买 2 个（双耳定位）
 8. 所有模块买【焊好排针】版（+1~3元），
    杜邦线直插免焊接；TT马达问"带端子线"

【📶 WiFi 升级兼容性】
----------------------------------------
 1. ESP32-S3 自带 WiFi/BLE，升级无需换板
 2. JSON 协议在串口与 WiFi TCP 同一格式
 3. 18650 电池组已必购，WiFi 无线模式同用它
 4. 板载天线勿贴金属；塑料/亚克力外壳 OK
 5. 移动模块占用 6-8 个 GPIO（电机4+编码器
    2+防跌落2），选型时预留

【📌 敲击定位方案】
----------------------------------------
 双耳 TDOA：Δt=(d2-d1)/c → θ=arcsin(c·Δt/D)
 D≈15cm（麦克风间距）
 策略：转向 θ → 前进 → 半路停再听，迭代修正
 防跌落：TCRT5000 朝下检测桌面边缘
